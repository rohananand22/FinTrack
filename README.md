# 💰 FinTrack

> My submission in **TechSolstice 2024 (MIT Bengaluru)**

An intelligent personal finance management platform that helps users track spending habits, monitor savings, and improve financial health through analytics, machine learning insights, and gamified financial goals.

---

##  Overview

FinTrack is a full-stack web application designed to make personal finance management engaging and insightful. Users can log into dummy bank accounts, analyze financial activity, track savings goals, and receive personalized recommendations to improve their spending habits.

The platform combines:

-  Financial Analytics
-  Machine Learning Insights
-  Transaction Management
-  Gamification Elements
-  Interactive Dashboards

to create a comprehensive financial wellness experience.

---

##  Features

###  User Authentication

- User signup and login
- Session management using Flask
- Secure account handling

###  Financial Dashboard

- Total account balance
- Monthly income tracking
- Monthly expense tracking
- Savings rate calculation
- Financial summary cards

###  Analytics & Insights

- Spending pattern analysis
- Savings performance monitoring
- Financial health indicators
- Dynamic dashboard updates

###  ML-Based Saving Tips

- Machine learning model analyzes user financial data
- Personalized recommendations for improving savings
- Data-driven financial guidance

###  Transaction Management

- Add new transactions
- Track recent transactions
- Store transaction history
- Dynamic transaction table updates

###  Gamification System

- Elixir Meter progression system
- Town Hall level advancement
- Reward-based financial tracking
- Visual progress indicators

###  Budget Goals

- Goal creation and tracking
- Progress visualization
- Savings target monitoring
